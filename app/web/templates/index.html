How it works

  1. Point at a folder on this computer that holds .calculationview or .hdbcalculationview files. Sub-folders become packages.
  2. Each file is parsed into the project database. Nothing leaves this machine.
  3. Browse the views list, open a view to see its steps as a graph and in plain English.
  4. Re-import the same folder at any time; notes stay, and are flagged when the view changed.

From a terminal: calcview import <folder> --db <file>.
